# AI & Human — Partners, Not Rivals

A React + Vite website explaining why AI will never take over humanity.

## Quick Start

```bash
npm install
npm run dev
```

Open **http://localhost:5174**

## Sections

- **Hero** — Bold statement with key stats
- **Why AI Cannot Replace Humans** — Consciousness, creativity, empathy
- **Human Edge** — 6 irreplaceable human qualities
- **Myths vs Facts** — Debunking AI takeover fears
- **The Future** — Human + AI collaboration
- **Gallery** — Visual story with bundled local images

## Tech

- React 18 + Vite 5
- All images bundled in `public/images/` (no broken external URLs)
- SafeImage component with fallback
